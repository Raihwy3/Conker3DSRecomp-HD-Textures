# Conker3DSRecomp-HD-Textures

HD texture pack and original dumped N64 textures for [Conker3DSRecomp](https://github.com/Raihwy3/Conker3DSRecomp).

## Usage (3DS / Emulator)

1. Download `texpack.bin` from the [Releases](https://github.com/Raihwy3/Conker3DSRecomp-HD-Textures/releases) page.
2. Place it on your SD card at:
   ```
   sdmc:/3ds/ConkerRecomp/texpack.bin
   ```
3. Enable **HD Textures** in the in-game Options menu.

## Contents

- `original/` — 7,787 original N64 textures extracted from `baserom.us.z64`.
- **Releases** — Pre-packed `texpack.bin` (2x upscaled `RGBA4` textures for `rt64-3ds`).
